# Vulkan Material System

This project is an attempt at creating a rudimentary material system in Vulkan, with support for albedo, normal, displacement, roughness, and ambient occlusion textures.
PBR theory is also implemented, including the Cook-Torrance BRDF alongside GGX normal distribution.
